# Security Policy

README Lens reads local repository metadata and documentation files. It does not make network requests or upload repository content.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Email the maintainer listed in the repository profile or use GitHub's private vulnerability reporting feature if it is enabled.

Include:

- Affected version or commit.
- Steps to reproduce.
- Expected and actual behavior.
- Any relevant terminal output.

The goal is to acknowledge valid reports within 72 hours and publish a fix or mitigation plan as soon as practical.
